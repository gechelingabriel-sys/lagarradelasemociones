# Garra de los miedos · Definir giro pedagógico

Versión separada del juego de máquina de garra. Está preparada para conservar intacto el proyecto original **“Genera sprites y monta juego móvil”**.

## Qué contiene

- Máquina de garra jugable en navegador.
- 7 monstruos diferenciados por color.
- Flechas, joystick arrastrable y botón **ATRAPAR**.
- Marcador de **JUGADAS** y **PREMIOS**.
- Patrón de captura recuperado: **FALLO → FALLO → ACIERTO**.
- Secuencia visual de descenso, agarre, elevación, balanceo y salida.
- Luma con bienvenida hablada mediante `speechSynthesis`.
- `js/puppet.js` anima la boca de Luma mientras habla.
- Pausa pedagógica tras una captura.
- Diseño responsive para móvil y escritorio.

## Ejecutar

No necesita instalación ni dependencias. Abre `index.html` en un navegador moderno.

Para GitHub Pages, sube toda la carpeta al repositorio y publica desde la rama principal.

## Importante sobre fidelidad

Este ZIP es una **reconstrucción funcional de la versión “Definir giro pedagógico”** basada en material recuperable del proyecto y en la captura proporcionada. No es una exportación byte por byte del Work original porque el código interno de ese Work no puede extraerse desde otro chat una vez agotado su acceso.

El proyecto original **“Genera sprites y monta juego móvil”** no se modifica.
